# Золото Башкирии

Демонстрационный адаптивный сайт-каталог натурального мёда с собственной пасеки в Буздякском районе Республики Башкортостан.

## Запуск
Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Перед реальными продажами
- заменить демонстрационные товары, цены и фотографии на подтверждённые;
- добавить реальные контакты продавца;
- подключить отправку заказов и оплату;
- настроить доставку и добавить юридическую информацию и политику обработки персональных данных.

Корзина работает локально в браузере. Форма заказа пока демонстрационная и не отправляет данные.
